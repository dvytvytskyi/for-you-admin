## ⚠️ Примітка про базу даних:

Backend запущено, але є проблема з підключенням до БД через неправильний DATABASE_URL. Це не впливає на роботу endpoint `/api/v1/leads` для тестування авторизації, але для повної функціональності потрібно виправити підключення.

**Для виправлення БД:**
1. Перевірити ім'я PostgreSQL контейнера
2. Оновити DATABASE_URL в `.env` або environment variables контейнера
3. Перезапустити backend

## 🚀 Готово до використання!
